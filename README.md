# Instagram agent skills — @marcvallfisio

Skill para Claude que gestiona el Instagram de @marcvallfisio (Tonus Fisioterapia, Tarragona): ideas, guiones de Reels, copys y hashtags, calendario, respuestas y métricas.

## Estructura
```
skills/instagram-marcvallfisio/
  SKILL.md            ← reglas y enrutado
  references/
    perfil.md         ← RELLENAR primero (datos de la cuenta)
    ideas-contenido.md
    guion-reel.md
    copy-hashtags.md
    calendario.md
    respuestas.md
    metricas.md
```

## Instalar en claude.ai
1. Rellena `references/perfil.md`.
2. Comprime la carpeta `instagram-marcvallfisio` en un .zip.
3. claude.ai → Settings → Capabilities → Skills → Upload skill.

## Uso
Ejemplos: "Dame 10 ideas para esta semana", "Guion de Reel sobre dolor de rodilla al bajar en trail", "Responde a este DM: …", "Revisa estas métricas: …".
